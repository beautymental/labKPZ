
## Завдання

### Завдання 1: Адаптер
- Створено класи `Logger`, `FileWriter`, `FileLoggerAdapter`.
- Вони реалізують шаблон "Адаптер" для логу файлів.

### Завдання 2: Декоратор
- Реалізовано героїв: `Warrior`, `Mage`, `Paladin`.
- Декоратори `HeroWithArmor`, `MageWithStaff`, `PaladinWithShield` додають інвентар до героїв.

### Завдання 3: Міст
- Створено класи для фігур: `Circle`, `Square`, `Triangle`.
- Реалізовано рендеринг за допомогою шаблону "Міст".

### Завдання 4: Проксі
- Реалізовано клас `SmartTextReader` для читання файлів.
- Додано проксі: `SmartTextChecker` для логування та `SmartTextReaderLocker` для обмеження доступу до файлів.

### Завдання 5: Компонувальник
- Створено класи для елементів розмітки: `LightNode`, `LightElementNode`, `LightTextNode`.
- Реалізовано можливість створення HTML-дерева.

### Завдання 6: Легковаговик
- Створено шаблон для зменшення споживання пам'яті у HTML-дереві за допомогою "Легковаговика".

## Вимоги

- PHP 7.4 або новіша версія.
- Наявність серверу для виконання PHP (наприклад, XAMPP, MAMP, або локальний сервер).

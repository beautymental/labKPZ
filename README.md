# Money Product Warehouse Reporting

## Опис

Проєкт реалізує систему управління грошима, товарами, складом та звітністю на PHP. Складається з наступних класів:
- `Money` — робота з грошима (ціла частина та копійки).
- `Product` — опис товару (назва, ціна, категорія).
- `Warehouse` — управління товарами на складі (додавання, видалення товарів, перегляд залишків).
- `Reporting` — формування звітів та накладних (прибуткова, видаткова, звіт по залишках).

## Встановлення
1. Скопіювати файли проєкту на сервер.
2. Переконатись, що сервер підтримує PHP 8.0 або новіше.
3. Налаштувати вебсервер 

## Використання
- Викликати методи класів для роботи з грошима, товарами та складуванням.
- Використовувати `Reporting` для генерації звітів та накладних.

## Приклад
```php
$money = new Money(100, 50);
$product = new Product('Apple', $money, 'Fruits');
$warehouse = new Warehouse();
$item = new WarehouseItem($product, 'kg', 50, '2025-03-10');
$warehouse->addItem($item);
echo Reporting::inventoryReport($warehouse);
```
